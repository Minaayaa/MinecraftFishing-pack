# Fishing Expansion resource pack

Textures for the Fishing Expansion plugin: fish, modular rods, the angler's compendium, the fight HUD and the
achievement icons. The plugin offers it to players when they join, so you don't need to install it by hand.

Download: https://raw.githubusercontent.com/Minaayaa/MinecraftFishing-pack/main/FishingExpansion-pack.zip

Plugin version 1.0.0 · sha1 `e81e46c5ef965b86d7fbf7698de36eee05259a2d`

In `plugins/FishingExpansion/config.yml`:

```yaml
resource-pack:
  mode: url
  url: "https://raw.githubusercontent.com/Minaayaa/MinecraftFishing-pack/main/FishingExpansion-pack.zip"
```
